# CS471 Library Project

A Django web application built through weekly labs for the CS471 course. It covers books, students, user accounts, and an image gallery.

The source code is in [`Desktop/libraryproject`](Desktop/libraryproject).

## What it includes

- `apps/bookmodule`: book pages, search, and create, edit, and delete pages for books and students
- `apps/usermodule`: registration, login, and logout
- `CS471_lab`: static HTML and CSS pages from the early labs

## Topics covered

- Django templates and URL routing
- HTML5 pages for links, text formatting, lists, and tables
- Simple and complex database queries
- One-to-one, one-to-many, and many-to-many model relationships
- Django forms
- Image upload with an image gallery
- User authentication

## Running the project

This repository cannot run as it is, because the `libraryproject` settings folder is stored as a Git submodule reference and its files are not included.

## Tools

Python, Django, SQLite, HTML, CSS
